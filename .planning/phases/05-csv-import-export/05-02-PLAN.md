## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser multipart request to WordPress handler | Method, authority, nonce, upload origin and request limits must be established before file access. |
| Uploaded CSV bytes to parser/validator | Malformed or oversized input can consume resources or confuse record/header boundaries. |
| Structured outcomes to admin HTML | Imported values, filenames and system reasons are untrusted at the rendering sink. |
