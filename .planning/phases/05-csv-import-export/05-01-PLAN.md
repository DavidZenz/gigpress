## Trust Boundaries

| Boundary | Description |
|---|---|
| CSV bytes to validated record | Untrusted file content becomes typed values and identity queries. |
| Validated record to custom tables/posts | A row can create or associate persistent WordPress/GigPress data. |
| Production source to compatibility evidence | Tests must prove the changed checkout and cannot accept empty or stale cases. |
